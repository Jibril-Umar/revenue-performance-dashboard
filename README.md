# 📊 Revenue Performance Dashboard

## 📌 Dashboard Overview
This Power BI dashboard tracks $623.45M in total revenue across 2,000 orders, offering detailed breakdowns by region, sales representative, product category, and payment method.

![Revenue Dashboard](https://github.com/Jibril-Umar/revenue-performance-dashboard/blob/main/dashboard33.PNG?raw=true)

## 🛠️ Tools & Technologies Used
* **Power BI:** Data modeling, DAX measures, and visual dashboard design.
* **SQL:** Database querying, data transformation, and cleaning.
* **Excel:** Raw data structuring and validation.

## 💡 Why I Enjoy Using These Tools
* **Power BI:** I love using Power BI because it allows me to take complex transactional data and turn it into clean, executive-ready visuals that tell an instant story.
* **SQL:** I enjoy writing SQL queries to ensure raw data integrity and extract precise data pipelines before visualization.
